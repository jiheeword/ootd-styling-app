# 👗 OOTD 오늘의 코디 (MVP BETA)

> **나와 비슷한 사람의 실제 코디로, 실패 없는 옷 쇼핑**
>
> 키·체형·퍼스널컬러가 비슷한 실제 사용자의 착장과 구매 경험을 기반으로, 온라인 패션 구매 실패를 줄여주는 AI 패션 커뮤니티 플랫폼을 목표로 합니다.

[![Vercel Deployment](https://img.shields.io/badge/Vercel-Deployed-success?logo=vercel)](https://temporary-sonic-dune-ubv08dc.vercel.app)

> ⚠️ **현재 버전은 서비스 구조와 사용자 경험을 검증하기 위한 MVP입니다.**
> 퍼스널컬러·체형 추천은 자가응답과 기본 추천 규칙을 기반으로 제공되며, 실제 AI 분석 모델과 쇼핑몰 상품 데이터 연동은 개발 예정입니다.

---

## 1. 해결하려는 문제

온라인에서 옷을 살 때 우리가 보는 사진은 대부분 **키가 크고 마른 모델의 착용샷**입니다. 그래서

- 모델에게는 예뻤던 옷이 내 체형에는 어울리지 않고,
- 평소 사이즈대로 샀는데 브랜드마다 핏이 달라 교환·반품을 반복하고,
- 출산·나이·생활 변화로 체형이 바뀐 뒤에는 "나한테 뭐가 맞는지" 기준 자체가 흐려집니다.

**OOTD 오늘의 코디**는 "모델에게 예쁜 옷"이 아니라 **"나와 비슷한 사람에게 잘 맞았던 옷"**을 찾게 해서 이 실패를 줄이려고 합니다.

## 2. 초기 타깃

- **35~55세 여성**
- 체형 변화를 겪었고, 온라인 쇼핑에서 사이즈·핏 실패를 자주 경험하는 고객

## 3. 핵심 차별점: 나와 비슷한 사람의 실제 착장 데이터

단순히 AI가 가상의 코디를 만들어 보여주는 서비스가 아닙니다.

- 사용자가 코디를 올릴 때 **키, 상·하의 사이즈, 체형, 퍼스널컬러, 착용 제품, 실제 착용 후기**를 함께 남깁니다.
- 내 프로필과 비교해 **나와 비슷한 사람의 착장**을 먼저 보여줍니다.
- 이렇게 쌓인 실제 착장·구매 경험 데이터에 AI 추천을 결합하는 것이 장기 목표입니다.

## 4. 기능 구현 현황

### ✅ 현재 실제 구현된 기능

| 기능 | 설명 |
| --- | --- |
| 반응형 OOTD 피드 | PC 4열 / 모바일 2열 카드, 스토리·필터 칩, 상세 모달(좋아요·스크랩·댓글), 착장 태그 핀 |
| 착용자 정보 표시 | 카드마다 `164cm` · `상의 M / 하의 28` · `웨이브 체형` · `여름 쿨톤` · 착용 후기 표시 |
| 내 매칭 프로필 | 키, 체중(선택), 상·하의 사이즈, 체형, 퍼스널컬러, 선호 스타일 입력 → **브라우저 localStorage에 저장** (새로고침해도 유지) |
| 나와 비슷한 사람 필터 | 아래 **기본 프로필 매칭 점수**로 게시물을 높은 순으로 정렬, 카드에 `나와 체형·톤 유사` 배지 표시 |
| 자가응답 기반 스타일 분석 | 5개 문항 응답을 `state.diagnosisAnswers`에 저장하고 쿨/웜 응답을 집계해 퍼스널컬러·체형 결과 생성, 결과 직접 수정 가능, 새로고침해도 유지 |
| 사진 촬영·업로드 | 웹캠/스마트폰 카메라 촬영, 앨범 선택, 미리보기 (사진은 서버로 전송되지 않음) |
| 커뮤니티 | 카테고리 탭, 글쓰기 |
| 맞춤 쇼룸 UX | 분석 결과에 따라 쇼룸 구성이 바뀌는 화면 흐름, 장바구니 담기·삭제·합계 |
| 반응형 레이아웃 | PC 상단 내비게이션 / 모바일 하단 탭, PC 뷰·모바일 뷰 전환 버튼 |

**기본 프로필 매칭 점수 (AI 정확도가 아닌 규칙 기반 점수, 100점 만점)**

| 조건 | 점수 |
| --- | --- |
| 체형 일치 | 35 |
| 퍼스널컬러 일치 | 25 |
| 키 차이 3cm 이내 (7cm 이내) | 20 (10) |
| 상의 사이즈 일치 | 10 |
| 하의 사이즈 일치 | 10 |

**자가응답 분석 규칙**

1. 금속 컬러·햇볕 반응 문항에서 쿨/웜 응답 수를 집계 (동점이면 햇볕 반응 응답 기준)
2. 컬러 명도 문항(밝고 부드러운 / 진하고 선명한)으로 계절 구분 → 봄·여름·가을·겨울
3. 체형 문항 응답으로 웨이브·스트레이트·내추럴 결정
4. 사진은 결과에 영향을 주지 않으며, 향후 AI 분석을 위한 입력으로만 받습니다.

### 🧪 현재 시뮬레이션(데모)인 기능

| 기능 | 현재 상태 |
| --- | --- |
| 상품 URL 분석 | **UX 시제품.** 샘플 상품 3개에만 미리 정한 분석 결과를 보여줍니다. 입력한 링크의 웹페이지를 읽지 않으며, 그 외 URL에는 결과를 만들지 않고 안내 문구만 표시합니다. |
| 가격·품절 알림 | **기능 데모.** 실제 가격·재고를 조회하지 않습니다. `DEMO` 버튼은 알림 화면 예시입니다. |
| 브랜드 상품 추천 | 쇼룸 상품·가격은 **예시 상품 데이터**이며 실제 판매 정보가 아닙니다. |
| 피드 게시물·커뮤니티 글 | MVP 검증용 **예시 데이터**입니다. 새로 올린 글은 새로고침하면 사라집니다. |
| 로그인·회원가입 | 화면 흐름만 구현되어 있으며 실제 계정은 만들어지지 않습니다. |

## 5. 수익 모델 (계획)

1. **제휴 구매 수수료** — 추천·착장 태그를 통해 제휴 쇼핑몰에서 구매가 일어나면 수수료
2. **브랜드 입점·광고** — 체형·톤별 타깃 고객에게 브랜드 상품 노출
3. **B2B 추천 위젯** — 쇼핑몰 상세페이지에 "나와 비슷한 체형의 구매자 후기·사이즈 추천" 위젯 제공

## 6. 첫 주얼리 실증 파트너: LAMURMUR

- 퍼스널컬러별 금속 컬러, 얼굴형별 귀걸이 크기, 의상 네크라인별 목걸이 길이를 추천하는 **주얼리 스타일링 기능**을 LAMURMUR 상품 데이터로 우선 검증할 예정입니다.
- LAMURMUR는 **첫 실증 브랜드**이며, OOTD 오늘의 코디는 특정 브랜드 전용이 아닌 **멀티브랜드 플랫폼**입니다. 같은 구조로 다른 패션·뷰티·주얼리 브랜드로 확장할 수 있습니다.
- 현재 저장소에는 LAMURMUR 실제 상품 데이터가 없어, 화면에는 안내 영역만 있습니다.

## 7. 기술 스택

- **Frontend**: HTML5, Vanilla CSS3 (Custom Properties, Flexbox, Grid), JavaScript (ES6+)
- **데이터 저장**: 브라우저 localStorage (백엔드 없음)
- **Icon**: Lucide Icons
- **Typography**: Pretendard, Montserrat, Playfair Display
- **Deployment**: Vercel (정적 호스팅)

## 8. 설치와 실행 방법

별도의 빌드 단계가 없습니다.

```bash
# 저장소 클론
git clone https://github.com/kimjaehyung-engineer/ootd-styling-app.git
cd ootd-styling-app

# 정적 서버로 실행 (카메라 기능은 localhost 또는 https에서만 동작)
npx serve .
# 또는
python -m http.server 8000
```

브라우저에서 `http://localhost:3000` (serve) 또는 `http://localhost:8000` (python)을 엽니다.

**둘러보기 순서 추천**

1. 메인 화면에서 **내 체형·사이즈 프로필 입력** → 저장
2. **나와 비슷한 사람** 필터로 매칭 점수 순 정렬 확인
3. **퍼스널 스타일 분석·쇼룸** 탭에서 5개 문항 응답 → 결과 확인·직접 수정 → 프로필에 반영
4. 쇼룸에서 상품 담기 → 장바구니에서 알림 데모 확인
5. 화면 하단 **MVP 개발현황**에서 구현/데모/개발 예정 구분 확인

저장된 프로필·분석 결과를 지우려면 브라우저 개발자도구 콘솔에서:

```js
localStorage.removeItem('ootd_my_profile_v1');
localStorage.removeItem('ootd_style_diagnosis_v1');
```
