## ✨ 핵심 기능 (Features)

### 1. 🖼️ OOTD 피드 & 인터랙티브 착장 태그 (Interactive Tagging)
- 사용자의 데일리 룩을 공유하는 그리드/피드 뷰
- 사진 속 착장 아이템 핀(Pin)을 클릭하여 브랜드, 제품명, 실시간 최저가, 구매처 즉시 확인
- 모달 기반 디테일 뷰어 및 사용자 반응(좋아요, 북마크, 공유, 댓글) 지원

### 2. 🎨 AI 퍼스널 컬러 & 체형 분석 (Personal Styling Engine)
- **4계절 12타입 퍼스널 컬러 진단**: 웜톤/쿨톤, 세부 계절별 최적 팔레트 및 워스트 컬러 제안
- **체형 유형별 맞춤 실루엣 분석**: 스트레이트, 웨이브, 내추럴 체형에 맞는 핏 & 기장 큐레이션
- **인터랙티브 아바타 프리뷰**: 실시간 톤/체형/주얼리 매칭 시각화

### 3. 🛍️ 스마트 가격할인 & 최저가 알림 (Price Drop Tracker)
- 관심 등록된 착장 아이템의 최근 30일 가격 변동 그래프 제공
- 역대 최저가 갱신 시 실시간 알림 뱃지 및 할인율 표시
- 원클릭 쇼핑몰 바로가기 아웃링크 연동

### 4. 🌙 다크/라이트 테마 & 반응형 UI
- 모바일(하단 탭바) 및 데스크톱(상단 글로벌 내비게이션) 최적화 반응형 레이아웃
- 고가독성 프리미엄 테마 시스템 (CSS 커스텀 변수 기반)

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: HTML5, Vanilla CSS3 (Custom Properties, Flexbox, Grid), JavaScript (ES6+)
- **Icon System**: Lucide Icons
- **Typography**: Pretendard, Montserrat, Playfair Display
- **Deployment**: Vercel

## 🚀 로컬 실행 방법 (Getting Started)

별도의 빌드 단계 없이 정적 웹 서버나 브라우저에서 바로 열 수 있습니다.

```bash
# 저장소 클론
git clone https://github.com/kimjaehyung-engineer/ootd-styling-app.git

# 폴더 이동
cd ootd-styling-app

# 브라우저에서 index.html 실행 (또는 VS Code Live Server / npx serve)
npx serve .
```
